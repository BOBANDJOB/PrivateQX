# Quantumult X 重写笔记

## reject 系列策略

| 策略 | 返回 |
|---|---|
| `reject` | HTTP 404，不附带任何内容 |
| `reject-200` | HTTP 200，不附带任何内容 |
| `reject-img` | HTTP 200，附带 1px gif |
| `reject-dict` | HTTP 200，附带空 JSON 对象 `{}` |
| `reject-array` | HTTP 200，附带空 JSON 数组 `[]` |

- 解压类场景实测：`reject-img` 解压失败、进度 100%；`reject-200` 解压失败、进度 0%。
- `url 302 <新链接>`：将匹配的链接重定向到后面的链接。

## 正则写法

| 写法 | 含义 |
|---|---|
| `[a-zA-Z0-9]{32}` | 32 位大小写字母与数字混合 |
| `[4-9]{1}` | 4 到 9 之间的一个数字 |
| `[0-9]{3,4}` | 3 位或 4 位纯数字 |
| `[a-zA-Z0-9]{16}$` | 16 位大小写字母与数字组合，并以此结尾 |
| `[0-9]+\.(jpg\|png)` | 只拦截纯数字命名的 jpg、png 图片 |
| `.*.png url reject-200` | 拦截所有 png 图片 |
| `202205\d{18}\.(png\|jpg)` | `202205` 后接 18 位数字的 jpg、png 图片 |
| `20220\d{3}\.(png\|jpg)` | `20220` 后接 3 位数字的 jpg、png 图片 |
| `\d{25}\.(png\|jpg) url reject-img` | 只拦截 25 位纯数字命名的 png、jpg 图片 |
| `img0[1-9]{1}\.luckincoffeecdn\.com` | 匹配 img01 ~ img09 前缀的域名，主机名中用 `*` 代替 |

### 结尾符 `$`

`\d{10}-\d{4}$`：只拦截以「10 位纯数字-4 位纯数字」结尾的短链接，后面带参数的长链接不拦截。

如果想拦截 `1234567890-1234?wx` 这类长链接，就去掉结尾符 `$`，只要前面部分匹配就会拦截。
